# Изменения

## 1.0.0 — WebHost

Финальная сборка на официальном шаблоне PulseSync с сохранением оформления, плеера, текстов, LRCLIB, очереди и закрепления плейлистов.

- Исправлен чёрный экран при открытии сохранённого плейлиста: удалена полная перезагрузка страницы.
- Исправлено обнаружение шапки плейлиста и добавлена постоянная кнопка закрепления по ссылке.
- Добавлено продолжение цвета шапки за верхней панелью поиска.
- Добавлен весь доступный список очереди с обновлением по событиям и порционной отрисовкой.
- Ошибка первоначального получения состояния плеера больше не прерывает запуск оформления; дальнейшие события обновляют состояние.
- Удалён неиспользуемый код старого загрузчика, согласованы версия, описание и npm lockfile.

Старые версии 1.0.x до переноса относятся к прежнему формату. Beta 1.1.0 — промежуточные сборки этой ветки; финальный номер по решению автора — 1.0.0.
