# SpotGlass 1.1.0-beta.4 — WebHost

Автор: ogressar. Тестовый перенос на официальный PulseSync-ExampleAddon и addon-sdk 0.18.0.

Сохранены оформление, нижний плеер, правая панель, тексты и LRCLIB. Запуск и остановка управляются WebHost. Состояние плеера приходит через SDK; тексты через resources; внешняя сеть через net.

Ограничение: медиатека собирает видимые ссылки из приложения и открытой коллекции. Полная фоновая загрузка всех плейлистов удалена вместе с доступом к внутреннему React store. Переходы используют доступные штатные ссылки.

Сборка не проверена в живом приложении; прохождение модерации не гарантируется. Старую версию отключить перед тестом.

### beta.2
Цвет существующей шапки плейлиста, альбома или исполнителя продолжается за верхней панелью поиска. На страницах без собственного цвета сохраняется обычный фон. Обновление выполняется по изменениям страницы, без отдельного таймера.

### beta.3
- Правая панель показывает текущий трек и всю доступную очередь. Длинный список раскрывается порциями по 50 треков, предыдущие треки свёрнуты.
- Кнопка «Изменить» открывает штатную очередь Яндекс Музыки для управления треками: SDK не предоставляет удаления, перестановки и перехода по индексу очереди.
- Кнопка «Закрепить этот плейлист» при открытом плейлисте и значки закрепления в медиатеке. Закрепления сохраняются локально отдельно для аккаунта и выводятся первыми.
- Если сохранённой ссылки уже нет в DOM, плейлист открывается обычным переходом страницы.

### beta.4
Исправлено обнаружение названия открытого плейлиста: блок кнопок больше не принимается за всю шапку. Постоянная кнопка «Добавить плейлист» позволяет закрепить его по ссылке и названию, даже когда автоматическое определение недоступно.
