# SpotGlass 1.0.0 — WebHost

Оформление Яндекс Музыки по мотивам Spotify Desktop. Автор: **ogressar**.

Это финальная версия новой ветки WebHost на основе [официального шаблона PulseSync](https://github.com/PulseSync-LLC/PulseSync-ExampleAddon).

[Скачать SpotGlass-1.0.0.pext](https://github.com/ogressar/SpotGlass/raw/refs/heads/main/releases/SpotGlass-1.0.0.pext)

## Возможности

- Адаптивный тёмный интерфейс, русская навигация, скруглённые панели и обновлённые иконки нижнего плеера.
- Верхний поиск и запуск «Моей волны» без перехода на отдельную страницу.
- Продолжение цвета шапки плейлиста, альбома или исполнителя за панелью поиска; обычные страницы сохраняют свой фон.
- Боковая медиатека с поиском и фильтрами. Закрепление открытого плейлиста или добавление по ссылке и названию; локальное сохранение отдельно для аккаунта.
- Панель «Сейчас играет»: обложка, название, исполнитель и альбом.
- Весь доступный список очереди, текущий трек, свёрнутые предыдущие треки и раскрытие длинного списка порциями по 50. «Изменить» открывает штатное управление очередью.
- Предпросмотр текста с раскрытием, подсветкой и плавной прокруткой по таймкодам. При отсутствии текста карточка скрыта.
- LRCLIB как запасной источник текстов, кеширование и отмена запросов при смене трека.
- Настройки правой панели, широкой медиатеки, компактных строк, акцента, «Моей волны», скрытия промоблоков и LRCLIB.

## Установка

1. Скачайте файл по ссылке выше и импортируйте в PulseSync с поддержкой WebHost.
2. Оставьте включённой одну версию SpotGlass. Отключите конфликтующее оформление.
3. Перезапустите Яндекс Музыку.

При переходе с beta 1.1.0 или старой 1.0.1 импортируйте 1.0.0 вручную: её номер меньше. Закрепления используют прежний ключ хранения и сохраняются при обычном обновлении. Не очищайте данные приложения.

Чтобы закрепить плейлист, откройте его и нажмите «Закрепить этот плейлист». Постоянная кнопка «+ Добавить плейлист» позволяет указать ссылку и название вручную. Значок булавки снимает закрепление.

## Особенности

Правая панель доступна при ширине окна от 1280 px. Автоматически собираются видимые ссылки медиатеки и открытой коллекции, а не весь аккаунт в фоне. Перестановка и удаление треков выполняются в штатной очереди Яндекс Музыки.

Переходы по сохранённым ссылкам используют штатные ссылки либо доступный клиентский роутер Next. Полная перезагрузка страницы не используется. Роутер и CSS-классы приложения могут измениться при обновлении Яндекс Музыки; при недоступности перехода показывается сообщение.

Для LRCLIB передаются название, исполнители, альбом и известная длительность трека; поддержку можно отключить в настройках. Текст без таймкодов отображается статично. Закрепления хранятся локально и не синхронизируются между устройствами.

## Разработка и проверка

Требуется Node.js 20.19+ или 22.12+ согласно ограничениям сборщика.

```sh
npm ci
npm test
npm run typecheck
npm run build
```

Результат сборки — `dist/SpotGlass`. Для импорта содержимое этой папки упаковывается в ZIP с расширением `.pext`; `metadata.json` должен находиться в корне архива.

Аддон использует `@pulsesync/addon-sdk` 0.18.0. Запуск и остановка управляются WebHost, состояние плеера и тексты поступают через SDK, внешние запросы выполняются через `host.net`. Лицензия официального шаблона сохранена в LICENSE и LICENSE.ru.md.

Сборка, проверка типов и регрессионные тесты проходят. Работа релизной версии в приложении подтверждена.
